MeetingKeeper — 영어 회의 실시간 자막 · 한글 번역 · 회의록
=========================================================

모든 처리는 이 컴퓨터 안에서만 이루어집니다. 인터넷 연결, 계정, 비용이 필요 없고
회의 음성은 어디에도 저장되지 않습니다 (텍스트만 저장).


1. 설치
-------
1) MeetingKeeper_1.zip, _2.zip, _3.zip … 을 모두 "같은 위치"에 압축 풉니다.
   - zip 우클릭 → [모두 압축 풀기] → 위치를  D:\  로 지정 (세 개 모두 똑같이)
   - 그러면 D:\MeetingKeeper 폴더 하나로 합쳐집니다.
   ※ 기본값(D:\MeetingKeeper_1 처럼 zip 이름 폴더)으로 풀면 안 됩니다.
2) D:\MeetingKeeper\MeetingKeeper.exe 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면: [추가 정보] → [실행]
   - 처음 한 번은 모델 파일 조각을 합치느라 10~30초 걸립니다.
3) 바탕화면 바로가기: MeetingKeeper.exe 우클릭 → [추가 옵션 표시] → [보내기] → [바탕 화면에 바로 가기 만들기]

※ 폴더 안의 models, _internal 폴더는 지우거나 옮기지 마세요.


2. 회의 전 준비 (처음 한 번)
---------------------------
- [상대 소리(출력)] : 팀즈 소리가 나오는 장치 (이어폰)를 고릅니다.
                      팀즈 설정 → 장치 → 스피커 에 선택된 것과 같은 장치여야 합니다.
- [내 마이크]       : 팀즈에서 쓰는 마이크를 고릅니다.
- [이름 사전]       : 내 이름, 자주 만나는 동료 이름을 미리 등록해 둘 수 있습니다.
- [저장 위치…]      : 회의록을 저장할 폴더 (기본: 이 폴더 안의 meetings)


3. 회의할 때
-----------
1) 팀즈 회의에 들어간 뒤 [시작]
2) 영어 자막이 먼저 나오고, 몇 초 뒤 그 아래에 한글 번역이 붙습니다.
3) 상대방은 Speaker 1, 2, 3… 으로 자동 구분됩니다.
   [Speaker 2 ▾] 를 누르면:
     - 이름 선택 / 새 이름 입력 → 그 사람의 모든 발언에 이름이 붙습니다
     - 한 사람이 두 Speaker 로 나뉘었으면 둘 다 같은 이름을 고르면 합쳐집니다
     - 한 문장만 잘못 붙었으면 [이 문장만 다른 화자로]
4) 이름을 붙여 두면 목소리를 기억해서, 다음 회의부터는 자동으로 이름이 붙습니다.
5) [항상 위] 를 체크하면 팀즈 위에 작은 창으로 띄워 둘 수 있습니다.


4. 회의가 끝나면
---------------
1) [정지] → 남은 문장 처리가 끝날 때까지 잠깐 기다립니다.
2) 화자 이름을 확인/수정합니다.
3) [회의 저장 (전문 + 요약)] → 회의 제목 입력 → 확인
   - 한글 요약은 회의 길이에 따라 몇 분 ~ 15분 정도 걸립니다 (그동안 다른 일 하셔도 됩니다).
4) 저장이 끝나면 폴더가 열립니다.

   20261012_01_주간 회의\
     20261012_01_회의록.docx   요약 + 전문 (영어/한글)
     20261012_01_요약.txt      요약만 (팀즈·메일에 붙여넣기용)

   - 파일 이름: 날짜_그날 몇 번째 회의
   - 회의 중에는 전문이 5초마다 자동 저장됩니다 (숨김 파일 ..._전문_자동저장.txt).
     프로그램이 갑자기 꺼져도 내용이 남아 있습니다.
   - 요약은 소형 AI 가 만들기 때문에 숫자·담당자는 전문으로 한 번 확인하세요.


5. 설정 팁
---------
- [CPU 절약] (기본 켜짐): 팀즈와 함께 쓸 때 컴퓨터가 버벅이지 않게 합니다.
  자막이 너무 늦게 나오면 꺼 보세요.
- [번역] Gemma(정확) 이 기본입니다. 번역이 많이 밀리면 NLLB(빠름) 으로 바꾸세요.
- 노트북은 전원을 연결한 상태가 더 빠릅니다.


6. 문제가 생기면
---------------
- 자막이 안 나옴: 프로그램 위쪽 "상대" 소리 막대가 움직이는지 확인
  → 안 움직이면 [상대 소리(출력)] 장치가 팀즈 스피커와 다른 것입니다. [새로고침] 후 다시 선택.
- 내 말이 안 잡힘: "나" 막대 확인 → [내 마이크] 장치 변경
- 점검 기능: 명령 프롬프트에서  MeetingKeeper.exe --selftest
  → data\selftest.txt 에 각 기능 점검 결과가 기록됩니다.
- 오류 기록: data\error.log
